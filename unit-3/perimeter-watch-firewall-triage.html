Security+ SY0-701 Obj 3.2 — Secure Enterprise Infrastructure Obj 1.2 — Zero Trust / PEP

Perimeter Watch — Thornbury Community Credit Union

Work the edge policy enforcement point. Ten connection attempts came through this shift — apply the ordered firewall policy below to each one, in the order the rules are written, and decide ALLOW or DENY. First match wins; anything left unmatched is dropped.

▲ You're the SOC analyst monitoring the edge PEP for Thornbury Community Credit Union. The network has three zones: the DMZ (10.20.10.0/24 — public banking portal and ATM transaction gateway), the corporate LAN (10.20.20.0/24 — employee machines), and the restricted core zone (10.20.30.0/24 — core banking database and backup server). Thornbury's ATM network partner connects from 198.51.100.0/24; their backup-maintenance contractor connects only from the static address 203.0.113.50.
New to CIDR notation? Click for a quick explainer on addresses like 10.20.20.0/24

An IP address is four numbers separated by dots, like 10.20.20.44. The /24 you see after some addresses (like 10.20.20.0/24) means "the first three numbers are fixed — only the last one can vary." So 10.20.20.0/24 covers every address from 10.20.20.1 through 10.20.20.254 — the whole corporate LAN, not one specific machine.

An address with no /24 after it (like 203.0.113.50) means exactly that one device — no range at all.

You don't need to do any subnet math for this lab — just check whether an address's first three numbers match the zone named in the rule. 10.20.20.44 matches 10.20.20.0/24. 10.20.30.44 does not.

Rules are evaluated top to bottom. The first rule that matches a connection decides its fate — later rules are never checked once one matches.
